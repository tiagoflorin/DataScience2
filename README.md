## 🏆 Proyecto Final: Predicción de Éxito en Spotify (Taeko Floran)

Este es el núcleo del repositorio. El proyecto busca predecir el alcance de canciones basándose en sus métricas técnicas.

### 🚀 Highlights del Modelo
* **Modelo:** Regresión Lineal con transformación logarítmica.
* **Métrica:** Logré un **R² de 0.7348** (un salto significativo desde el 0.66 del modelo base).
* **Integración:** Conexión vía API con **Last.fm** para validación de tendencias en tiempo real (Top 10 Argentina).

## 📂 Estructura del Curso

A lo largo de la cursada, cubrimos los pilares fundamentales de la Ciencia de Datos:

### 1. Exploratory Data Analysis (EDA)
Análisis estadístico descriptivo, detección de outliers y visualización con Seaborn/Matplotlib. 
* *Hito:* Corrección de asimetría en la variable 'streams' para mejorar la capacidad predictiva.

### 2. Feature Engineering & Preprocesamiento
Limpieza de datasets, manejo de valores nulos y normalización de variables. 
* *Hito:* Implementación de transformaciones para tratar datos altamente sesgados.

### 3. Machine Learning: Regresión
Entrenamiento, testeo y validación de modelos. Uso de métricas (MSE, RMSE, R²) para evaluar el desempeño.

### 4. Integración de APIs
Uso de librerías como `requests` y `spotipy` para enriquecer datasets estáticos con información dinámica.
